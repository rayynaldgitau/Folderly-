# Security Policy

## Reporting a Vulnerability

Foldy is a local desktop file manager with filesystem write and delete capabilities. If you discover a security vulnerability (such as path traversal, command injection, or CSP bypass):

- **Do not** open a public GitHub issue.
- Report it privately via [GitHub Security Advisories](https://github.com/rayynaldgitau/Folderly-/security/advisories/new) or email `raynaldgitau@gmail.com`.

Please include steps to reproduce, affected OS/version, and potential impact.
